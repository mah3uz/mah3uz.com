## The problem

Database GUIs are heavy, and `psql`, `mysql` and `sqlite3` each have their own habits. When you hop between projects
all day, that adds up. Quarry gives every database the same fast, consistent interface, right in the terminal you
already have open.

## What it does

- **Connect** to PostgreSQL, MySQL, MariaDB and SQLite with one tool.
- **Explore** schemas, tables and columns without writing a query first.
- **Write and run** SQL in an editor built for it, and page through results as a proper table.
- **Stay on the keyboard** from start to finish.

## Get it

Quarry is published through my Homebrew tap, alongside Insensical. Installation steps live on
